## 📖 About

Entity Counter displays a live count of all loaded entities split by category — mobs, items, projectiles, tile entities — with a configurable colour-coded HUD panel.

---

## ✨ Features
<a name="features"></a>

- **Live Count** — updates every tick.
- **Category Breakdown** — hostile, passive, items, vehicles, tile entities.
- **TPS Correlation** — shows entity count vs server TPS graph.
- **Lag Warning** — alert when entity count exceeds configured threshold.
- **Per-Chunk Mode** — count entities in the current chunk only.
- **Toggle Key** — quick on/off.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
